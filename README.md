# Movie Review Summarizer — Advanced AI Final Project

An end-to-end project for sentiment analysis and summarization of movie reviews. It includes data preprocessing, word-embedding experiments, a fine-tuned DistilBERT sentiment classifier, extractive TF‑IDF summarization, and a generative summarizer integration (Gemini API).

---

## Project Overview

- **Sentiment Classification** — Fine-tuned DistilBERT model (93%+ accuracy), stored under `models/bert_sentiment/`
- **Extractive Summarization** — TF‑IDF sentence ranking, implemented in `app.py`
- **Generative Summarization** — Gemini API wrapper, implemented in `app.py` (requires `GEMINI_API_KEY`)
- **Word Embeddings** — Word2Vec model (100-dim), trained in Notebook 1

---

## AI Techniques Used (from course)

| Technique | Implementation |

| Transformer / LLM (DistilBERT) | Notebook 2 (`models/bert_sentiment/`) |

## Running the Notebooks

Run the four notebooks **in order** (01 → 02 → 03 → 04). Each depends on outputs from the previous step.

### Notebook 1: Data Exploration & Preprocessing
**File:** `01_data_exploration_preprocessing.ipynb`

**What it does:** Loads `data/IMDB_Dataset.csv`, performs EDA, cleans text, balances classes, trains Word2Vec embeddings, and splits data into train/val/test sets.

**Prerequisites:** `data/IMDB_Dataset.csv` must exist.

**Outputs generated:**
- `data/train.csv` — training split (~40K reviews)
- `data/val.csv` — validation split (~5K reviews)
- `data/test.csv` — test split (~5K reviews)
- `models/word2vec_imdb.model` — Word2Vec embeddings (100-dim)
- `outputs/01_eda_distribution.png` — class distribution chart
- `outputs/02_wordclouds.png` — word clouds for positive/negative reviews
- `outputs/03_word2vec_tsne.png` — t-SNE visualization of embeddings

**Run time:** ~10–20 minutes

---

### Notebook 2: BERT Sentiment Classification
**File:** `02_bert_sentiment_classification.ipynb`

**What it does:** Fine-tunes DistilBERT on binary sentiment classification. Also trains classical baselines (Naive Bayes, Logistic Regression, SVM) for comparison.

**Prerequisites:** `data/train.csv` and `data/val.csv` from Notebook 1.

**Outputs generated:**
- `models/bert_sentiment/` — fine-tuned DistilBERT weights, config, and tokenizer
- `outputs/04_bert_training_curves.png` — training loss and accuracy curves
- `outputs/09_bert_confusion_matrix.png` — confusion matrix on test set

**Run time:** ~2–3 hours on CPU; ~20–30 minutes on GPU

> **GPU note:** PyTorch will use GPU automatically if available. Check with `torch.cuda.is_available()`.

---

### Notebook 3: T5 Summarization & Prompt Engineering
**File:** `03_t5_summarization_prompt_engineering.ipynb`

**What it does:** Experiments with extractive (TF‑IDF) and generative summarization. Tests four style-specific prompt strategies: concise, audience, critic, and chain-of-thought.

**Prerequisites:** `data/test.csv` from Notebook 1; optionally uses `models/bert_sentiment/` from Notebook 2.

**Outputs generated:**
- `outputs/06_prompt_rouge_evaluation.png` — ROUGE scores by prompt style
- `outputs/08_keywords.png` — keyword extraction visualization
- Example summaries and ROUGE metrics printed to notebook

**Run time:** ~30 minutes to 1 hour

---

### Notebook 4: Evaluation & Model Comparison
**File:** `04_evaluation_baseline_comparison.ipynb`

**What it does:** Comprehensive evaluation — confusion matrices, ROUGE scores, per-class metrics, and model comparison charts.

**Prerequisites:** Outputs from Notebooks 1–3.

**Outputs generated:**
- `outputs/07_model_comparison.png` — bar chart comparing model accuracies
- `outputs/rouge_scores_by_prompt.csv` — detailed ROUGE results table

**Run time:** ~5–10 minutes

## Using the Web Frontend

Once the Flask server is running:

1. Open your browser and go to `http://localhost:5000/`
2. You will see the **Movie Review Analyser** interface (dark theme with accent colors)
3. Paste or type a movie review in the text area
4. Choose a summarization method:
   - **TF‑IDF** — fast, no API key needed (default)
   - **Gemini** — more fluent summaries, requires `GEMINI_API_KEY` in `.env`
5. Click **Analyse**

**Results displayed:**
- Sentiment label (Positive / Negative) with probability scores
- Four summary variations: concise, audience-focused, critic-style, chain-of-thought
- Word count of the original review

## API Endpoints

### `GET /health`
Returns server status and device info (CPU or GPU).

### `POST /analyse`
Analyses a movie review for sentiment and generates summaries.

**Request body:**
```json
{
  "review": "Your review text here",
  "method": "tfidf"
}
```

Set `"method": "gemini"` to use the Gemini generative summarizer (requires API key).

**Response:**
```json
{
  "sentiment": { "label": "Positive", "positive_prob": 0.97, "negative_prob": 0.03 },
  "summaries": {
    "concise": "...",
    "audience": "...",
    "critic": "...",
    "cot": "..."
  },
  "word_count": 42
}
```

**Example (curl):**
```bash
curl -X POST http://localhost:5000/analyse \
  -H "Content-Type: application/json" \
  -d '{"review": "I loved the movie, it was brilliant and moving.", "method": "tfidf"}'
```
